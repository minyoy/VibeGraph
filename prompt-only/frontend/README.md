# VibeGraph Frontend

React + Vite + Tailwind CSS 기반 프론트엔드

## 빠른 시작

```bash
cd frontend
npm install
cp .env.example .env.local    # .env.local 파일 편집 후
npm run dev
```

앱: http://localhost:5173

## 환경변수

| 변수 | 설명 |
|------|------|
| `VITE_API_BASE_URL` | 백엔드 API URL (기본: /api) |
| `VITE_APPLE_MUSIC_DEVELOPER_TOKEN` | Apple Music Developer JWT 토큰 |
